# NovaTech Store

NovaTech Store is a responsive electronics e-commerce website built with HTML, CSS, and JavaScript.

## Features

- Dynamic products using DummyJSON API
- Product search
- Category filtering
- Price filtering
- Product sorting
- Product details
- Add to Cart
- Increase and decrease product quantity
- Remove products from cart
- Clear Cart
- Cart subtotal
- LocalStorage cart persistence
- Checkout form validation
- Order summary
- Order confirmation
- Contact form
- Responsive design
- Loading and error states

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DummyJSON API
- LocalStorage

## Project Purpose

This project was built as a practical front-end development project to improve skills in JavaScript, DOM manipulation, API integration, filtering, shopping cart logic, form validation, and responsive web design.
